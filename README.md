# Traffic record

Per-day clone and view counts for philpaz/recusal, captured from GitHub's traffic API by
`.github/workflows/traffic.yml` on main. GitHub keeps this data for 14 days and then
discards it; this branch keeps it. One row per day in `clones.csv` and `views.csv`
(`date,count,uniques`), totals in `SUMMARY.md`, every file written by the workflow through
the contents API. The record begins at the first capture, 2026-11-05. Clones and views
before 2026-10-22 were never captured and are not on record; nothing here is estimated.

Data only: no code on this branch is run anywhere.
